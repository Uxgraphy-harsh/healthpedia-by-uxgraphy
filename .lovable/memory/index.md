# Healthpedia - Health App Design System

## Colors (HSL in index.css)
- Primary: pink `340 100% 80%`
- Secondary: `340 80% 70%`
- Accent: cyan `187 92% 53%`
- Background: warm white `40 33% 97%`
- Dark header: `#2C0011`
- Health status: good (green), watch (amber), alert (red)

## Typography
- ALL text: Geist (sans-serif) — no other fonts
- No serif fonts anywhere

## Design
- Glass cards, rounded 2xl, soft shadows
- Gradient buttons, mobile-first (max-w-md)
- Bottom nav: Summary, Reminders, Ask AI, Records, Profile
- Onboarding stored in localStorage
- Summary page has dark maroon header with health score
